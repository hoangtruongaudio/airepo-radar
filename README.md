# AI REPO RADAR V2.4 – Video & Demo

## Cách dùng
1. Giải nén file ZIP, mở `index.html` bằng Chrome/Live Server hoặc cập nhật `index.html` trên GitHub Pages.
2. Tìm repo → nhấn **Phân tích** → chọn tab **▶ Video & Demo**.
3. Với video MP4/WebM từ đường dẫn nguồn: nhấn nút phát. Với YouTube/Vimeo: nhấn **Xem tại đây** để tạo khung phát chỉ khi bạn yêu cầu.
4. Với tệp đính kèm GitHub hoặc video từ trang ngoài: dùng **Mở liên kết gốc** (trang ngoài có thể chặn nhúng).

## Giới hạn
- Chỉ tìm video từ các đường dẫn xuất hiện trong README chính: YouTube, Vimeo, MP4/WebM/MOV, GitHub user-attachments. Không tự quét toàn bộ mã nguồn, Releases, Docs hoặc Internet.
- Một số video không phát trực tiếp do chính sách của trang nguồn, định dạng hoặc trình duyệt; luôn có liên kết gốc để mở.
- Không có kết quả ≠ repo không có video.
- Không lưu hay tự tải video về máy; không dùng AI offline; Gemini tùy chọn và API key không được nhúng vào GitHub Pages.
- Các nội dung AI là phân tích từ tài liệu, không phải kết quả chạy thử; đánh giá Windows cần được kiểm chứng theo hướng dẫn thực tế của repo.

## Cập nhật GitHub Pages
Vào repository `ai-repo-radar` → Add file / Upload files → tải `index.html` mới lên thư mục gốc, ghi Commit changes. Sau khi Pages cập nhật, tải lại trang để thấy V2.4.
